# Routine Me — پروژه Flutter

این پروژه منبع اپلیکیشن پیگیری کارهای روزانه است. اطلاعات کارها و سابقهٔ تیک‌ها با `shared_preferences` به‌صورت محلی روی دستگاه نگهداری می‌شوند.

## امکانات
- افزودن، ویرایش و حذف کارها
- ثبت انجام کار برای هر روز و جلوگیری از تیک تکراری همان روز
- درصد پیشرفت روزانه
- شمارش مجموع دفعات انجام هر کار و رکورد روزهای متوالی
- آمار ۷ و ۳۰ روز اخیر
- تقویم فعالیت
- رابط فارسی/انگلیسی و راست‌چین/چپ‌چین
- تم روشن، تاریک و سیستم
- یادآوری روزانه با انتخاب ساعت

## ساخت پروژه کامل اندروید و APK در Windows
1. نصب Flutter SDK و Android Studio و تکمیل Android SDK.
2. ZIP را استخراج کنید و در ترمینال به پوشه‌ای بروید که می‌خواهید پروژه کامل در آن ساخته شود.
3. یک پروژه Flutter با پشتیبانی اندروید بسازید: `flutter create --platforms=android routine_me_app`
4. فایل `routine_me/lib/main.dart` را از این بسته در مسیر `routine_me_app/lib/main.dart` کپی کنید و فایل `pubspec.yaml` این بسته را با فایل پروژه جدید جایگزین کنید.
5. وارد پوشه `routine_me_app` شوید و اجرا کنید:
   ```bash
   flutter pub get
   flutter doctor
   flutter build apk --release
   ```
6. خروجی در مسیر زیر ساخته می‌شود:
   `build/app/outputs/flutter-apk/app-release.apk`

## نکته مهم درباره یادآوری‌ها
برای نصب و زمان‌بندی اعلان‌ها، مجوز اعلان را در Android و در صورت نیاز به زمان‌بندی دقیق، تنظیمات مجوزهای نسخه اندروید مقصد را بررسی کنید. این بسته سورس اپلیکیشن است، نه پروژهٔ کامل دارای فایل‌های پلتفرم و نه APK کامپایل‌شده. برای تولید APK باید مراحل بالا را در محیطی با Flutter و Android SDK انجام دهید. سورس در این محیط با Flutter اجرا و کامپایل نشده است.
